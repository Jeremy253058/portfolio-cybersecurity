# Publication — GitHub Pages

Le dépôt contient le site statique HTML/CSS/JS ainsi qu'un workflow GitHub Actions destiné à publier les fichiers présents à la racine.

Pour activer la publication automatisée, ouvrir Settings → Pages, sélectionner la source GitHub Actions si l'option est disponible et enregistrer.

À noter : le connecteur GitHub utilisé pour cette intégration crée les fichiers texte, mais ne prend pas en charge de façon fiable le transfert des fichiers binaires depuis cette session. Les captures image du dossier `images/` et le véritable fichier `documents/CV.pdf` doivent être importés séparément avant que toutes les pages aient leurs visuels et que le téléchargement du CV fonctionne.
